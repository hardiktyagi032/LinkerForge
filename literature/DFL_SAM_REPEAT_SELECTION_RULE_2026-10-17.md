# Preregistered repeat and freeze rule

This rule is fixed before inspecting seeds 17/31 and before any CAID3 inference. Train `multiscale_features` and `boundary_plus_query` at seeds 17 and 31, complementing completed seed 7, on the CAID3-protected filtered data. Match the existing SAM-like disorder-transfer baseline's seeds, frozen ESM-2, training schedule, loss, score channel, and development coverage. The four jobs form two separate two-trial rounds, each capped at six GPU-hours.

Rescore all nine best checkpoints (three baselines, three per variant) on the same frozen development residues. Verify rescored APS equals each training manifest's selected APS before computing Fmax. Primary selection is **mean development APS** across seeds 7/17/31. An eligible variant must beat matched baseline mean APS and may not lose more than 0.02 absolute mean no-positive-protein proxy specificity versus that baseline; report per-seed specificity and any failures. If multiple variants qualify, select highest mean APS; mean Fmax is a secondary diagnostic, not a replacement for APS. Select the seed checkpoint with development APS closest to its variant's three-seed mean (fixed rule that avoids cherry-picking the best seed). If no variant qualifies, freeze the matched baseline by the same closest-to-mean rule. Freeze checkpoint path and SHA-256, variant, source/data/config hashes, exact metric table, and selection-rule hash in a manifest **before** reading CAID3 labels for this comparison.

Only then run the one-time CAID3 common-27 comparison against all seven released predictor files with the official evaluator and record APS, AUC-ROC, Fmax, raw counts, and coverage. CAID3 is public and previously inspected: this is a locked retrospective, not a fresh independent test or a basis for another architecture change. A separate untouched homology-audited set is needed for a publishable superiority claim.
